# Дерево mod в zip (`npm run pack`)

В архиве:

```
SilverFish/
  Content/
    Localization/Game/en/Game.locres   ← build/Game.locres
    Paks/                              ← из fonts/ и опционально SilverFish/Content/Paks/
```

**Шрифты:** **`fonts/SilverFishRU_FONTS_P.pak`**

Распаковать zip в **корень игры**. Язык: **English**.
