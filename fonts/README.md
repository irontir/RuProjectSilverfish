# Шрифты (font-pak)

**`SilverFishRU_FONTS_P.pak`** — кириллица в UI. Без него в игре часто пустой текст вместо русского.

При **`npm run pack`** файл попадает в zip как  
`SilverFish/Content/Paks/SilverFishRU_FONTS_P.pak`.

Если файла нет — возьми из [ProjectSilverfishRus](https://github.com/costilman/ProjectSilverfishRus/releases) или из игры (`SilverFish/Content/Paks/`).
