# Перевод

| Файл | Назначение |
|------|------------|
| **`translation_map.json`** | Словарь EN → RU — **основной файл для перевода** |
| **`glossary.json`** | Термины и правила — редактируешь вручную |
| **`glossary_for_llm.md`** | Промпт для нейросети — `npm run glossary` |

### translation_map.json

- **Ключ** — английский `SourceString` из игры (**не менять**)
- **Значение** — русский текст; `""` = ещё не переведено

```powershell
npm run scan
# правка translation_map.json
npm run build     # → build/Game.locres.txt
```

`scan` рекурсивно проверяет весь экспорт `Classes`, включая `Maps`. Уже переведённый `SourceString` сохраняет перевод; новый или изменённый исходный текст добавляется с `""`. Числа, пустые значения, пунктуация и пути Unreal автоматически исключаются.

Сканер рекурсивно обходит все JSON в `Classes`, но разбирает только файлы, содержащие одновременно `SourceString` и `LocalizedString`.

FText внутри `UserDefinedEnum` исключается автоматически: отображаемые значения enum могут использоваться игровой логикой как идентификаторы. Также исключается FText внутри `TextRenderComponent` — это пространственные надписи на дверях и табличках, игровой шрифт которых не содержит кириллицу. Фильтрация основана на типе экспортированного объекта и не зависит от пути, GUID или содержимого строки.
