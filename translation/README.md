# Перевод

| Файл | Назначение |
|------|------------|
| **`translation_map.json`** | Словарь EN → RU — **основной файл для перевода** |
| **`ignored_keys.json`** | Служебные Unreal-ключи, которые нельзя добавлять в `locres` |
| **`glossary.json`** | Термины и правила — редактируешь вручную |
| **`glossary_for_llm.md`** | Промпт для нейросети — `npm run glossary` |

### translation_map.json

- **Ключ** — английский `SourceString` из игры (**не менять**)
- **Значение** — русский текст; `""` = ещё не переведено

```powershell
npm run scan
# правка translation_map.json
npm run build     # → build/Game.locres.txt
```

`scan` рекурсивно проверяет весь экспорт `Classes`, включая `Maps`. Уже переведённый `SourceString` сохраняет перевод; новый или изменённый исходный текст добавляется с `""`. Числа, пустые значения, пунктуация и пути Unreal автоматически исключаются.

FText внутри `TextRenderComponent` также исключается автоматически. Это 3D-надписи на дверях и табличках: используемый ими игровой шрифт не содержит кириллицу, поэтому перевод делал надписи невидимыми. Такие надписи остаются на английском, тогда как одноимённый текст обычного интерфейса продолжает переводиться.

### ignored_keys.json

Исключения задаются парой `Namespace` + `Key`. Такие записи отбрасываются при сканировании и повторно проверяются при создании `Game.locres.txt`, поэтому служебный текст не вернётся после следующего обновления экспорта.
